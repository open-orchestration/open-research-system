## Purpose and Scope
This document provides a high-level overview of the GPT Researcher system architecture, core components, and capabilities. GPT Researcher is an autonomous research agent designed for both web and local research on any given task, producing detailed, factual, and unbiased research reports with citations [README.md23-27](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L23-L27) Inspired by the [Plan-and-Solve](https://arxiv.org/abs/2305.04091) and [RAG](https://arxiv.org/abs/2005.11401) papers, it addresses misinformation and speed through parallelized agent work [README.md27-28](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L27-L28)
This overview covers the fundamental architecture and component relationships. For detailed information about specific subsystems, refer to the subsequent pages in this wiki.
**Sources:** [README.md23-30](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L23-L30) [gpt_researcher/agent.py1-5](https://github.com/assafelovic/gpt-researcher/blob/b364917f/gpt_researcher/agent.py#L1-L5)
## System Architecture
GPT Researcher utilizes a "planner" and "execution" agent pattern [README.md54-56](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L54-L56) The system is highly modular, supporting 25+ LLM providers, multiple search retrievers, and various document formats [README.md76-84](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L76-L84)

## Research Workflow
The standard research pipeline follows these steps:
  1. **Task Initialization** : A task-specific agent is created based on the research query [README.md63](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L63-L63)
  2. **Query Decomposition** : The `ResearchConductor` generates a set of questions that collectively form an objective opinion on the task [README.md64](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L64-L64)
  3. **Information Gathering** : A crawler agent (via `BrowserManager`) gathers information for each question from online or local resources [README.md65](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L65-L65)
  4. **Source Tracking** : Each resource is summarized and its source is tracked [README.md66](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L66-L66)
  5. **Aggregation** : Findings are filtered and aggregated into a final research report exceeding 2,000 words if configured [README.md67-79](https://github.com/assafelovic/gpt-researcher/blob/b364917f/README.md?plain=1#L67-L79)
