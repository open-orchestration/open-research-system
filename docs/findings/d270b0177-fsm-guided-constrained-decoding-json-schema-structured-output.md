This finding grounds FSM-guided / constrained decoding — the mechanism by which an LLM is forced to emit output conforming to a formal constraint (regular expression, context-free grammar, structured data format) *by construction* — on its primary source, Willard & Louf's "Efficient Guided Generation for Large Language Models" (the Outlines library) [c328a44fb]. It complements the topic-10 prompting-ladder findings (d0cce1cec, d0b1fc5c6) on a distinct axis: those concern reasoning quality (CoT / self-consistency / ToT), whereas this concerns output-format reliability — guaranteeing the *shape* of the generated text rather than improving the reasoning that produces it.

**Core reformulation: generation as transitions over a finite-state machine.** The paper shows that neural text generation can be constructively reformulated in terms of transitions between the states of a finite-state machine (FSM), and that this framework yields an efficient approach to guiding text generation with regular expressions and context-free grammars [c328a44fb]. A guiding regular expression is given in its FSM formulation — a 5-tuple (Q, Σ, δ, q₀, F): state set Q, alphabet Σ, transition function δ : Q×Σ → Q, start state q₀, and accept states F — and the FSM state reached after sampling each vocabulary token is tracked during the LLM sampling loop, so the machine is continued without re-reading the growing sample sequence from the beginning each step [c328a44fb].

**The precomputed index and the O(1) efficiency claim.** The naive ("common and sufficient") approach repeatedly evaluates over the entire vocabulary at each step to decide which tokens are valid, then sets the probabilities of invalid tokens to zero — a fixed **O(N)** cost per generated token, where N is the size of the LLM's vocabulary [c328a44fb]. The paper's contribution is to pre-process the vocabulary against the regular expression's FSM and build an index: a map **σ : Q → P(V)** connecting each FSM state to the set of vocabulary elements the FSM will accept in that state (constructed by Algorithm 4) [c328a44fb]. Using a hash-map for σ makes the masking step cost only **O(1) on average**, so the overall result is "an algorithm that costs O(1) on average" rather than scanning the full vocabulary per step [c328a44fb].

**Logit masking.** Because the next token is drawn from a Categorical distribution over the output logits α, the method restricts the support of that distribution by applying a boolean mask m : P(V) → {0,1}^N, computing an un-normalized conditional distribution α̃ = m(S̃) ⊙ α [c328a44fb]. Invalid tokens have their probability set to zero before sampling, so the output conforms to the constraint by construction — the index supplies the per-step mask m directly, rather than relying on post-hoc validation or retry [c328a44fb].

**Extension to context-free grammars and structured data formats.** Regular expressions cover regular languages; the indexing approach is extended to CFGs by way of **pushdown automata (PDA)** and augmentations to LALR(1) parser components and operations, allowing efficient guided generation according to popular data formats and programming languages — the paper names JSON, Python, and SQL as examples [c328a44fb]. This is the path by which constrained decoding produces output valid against a structured grammar (e.g. JSON), which is what makes reliable structured tool/function-call output possible. (Note: the source grounds JSON as a *data format* reachable through the CFG/LALR(1) extension; it does not use the term "JSON schema" or describe schema-keyword-level constraint compilation — see residual gaps.)

**Synthesis — relevance to the citation-gated engine.** The engine's promotion gate depends on *structured* LLM judging: constrained, parseable verdicts for faithfulness and relevance (cf. the LLM-judge finding dfa42bc8a and the RAG-Triad finding d4c45dd7e). FSM/grammar-guided decoding is the decoding-time mechanism that makes such structured output reliable *by construction* — the model can only emit tokens the FSM/PDA accepts, so a valid verdict object is guaranteed rather than obtained through parse-and-retry on free-form text [c328a44fb]. The paper frames exactly this guarantee as enabling "the construction of reliable interfaces by guaranteeing the structure of the generated text" [c328a44fb].
