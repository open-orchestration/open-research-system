## Faithfulness
The **Faithfulness** metric measures how factually consistent a `response` is with the `retrieved context`. It ranges from 0 to 1, with higher scores indicating better consistency.
A response is considered **faithful** if all its claims can be supported by the retrieved context.
To calculate this: 1. Identify all the claims in the response. 2. Check each claim to see if it can be inferred from the retrieved context. 3. Compute the faithfulness score using the formula:
Faithfulness Score=Number of claims in the response supported by the retrieved contextTotal number of claims in the response
### Example

```
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-1)from openai import AsyncOpenAI
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-2)from ragas.llms import llm_factory
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-3)from ragas.metrics.collections import Faithfulness
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-4)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-5)# Setup LLM
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-6)client = AsyncOpenAI()
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-7)llm = llm_factory("gpt-4o-mini", client=client)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-8)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-9)# Create metric
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-10)scorer = Faithfulness(llm=llm)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-11)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-12)# Evaluate
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-13)result = await scorer.ascore(
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-14)    user_input="When was the first super bowl?",
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-15)    response="The first superbowl was held on Jan 15, 1967",
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-16)    retrieved_contexts=[
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-17)        "The First AFL–NFL World Championship Game was an American football game played on January 15, 1967, at the Los Angeles Memorial Coliseum in Los Angeles."
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-18)    ]
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-19))
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-0-20)print(f"Faithfulness Score: {result.value}")

```

### How It’s Calculated
Example
**Question** : Where and when was Einstein born?
**Context** : Albert Einstein (born 14 March 1879) was a German-born theoretical physicist, widely held to be one of the greatest and most influential scientists of all time
**High faithfulness answer** : Einstein was born in Germany on 14th March 1879.
**Low faithfulness answer** : Einstein was born in Germany on 20th March 1879.
Let's examine how faithfulness was calculated using the low faithfulness answer:
  * **Step 1:** Break the generated answer into individual statements.
    * Statements:
      * Statement 1: "Einstein was born in Germany."
      * Statement 2: "Einstein was born on 20th March 1879."
  * **Step 2:** For each of the generated statements, verify if it can be inferred from the given context.
    * Statement 1: Yes
    * Statement 2: No
  * **Step 3:** Use the formula depicted above to calculate faithfulness.
Faithfulness=12=0.5

### Faithfulness with HHEM-2.1-Open
[Vectara's HHEM-2.1-Open](https://vectara.com/blog/hhem-2-1-a-better-hallucination-detection-model/) is a classifier model (T5) that is trained to detect hallucinations from LLM generated text. This model can be used in the second step of calculating faithfulness, i.e. when claims are cross-checked with the given context to determine if it can be inferred from the context. The model is free, small, and open-source, making it very efficient in production use cases.
To use the model to calculate faithfulness:

```
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-1)from ragas.dataset_schema import SingleTurnSample
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-2)from ragas.metrics import FaithfulnesswithHHEM
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-3)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-4)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-5)sample = SingleTurnSample(
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-6)        user_input="When was the first super bowl?",
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-7)        response="The first superbowl was held on Jan 15, 1967",
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-8)        retrieved_contexts=[
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-9)            "The First AFL–NFL World Championship Game was an American football game played on January 15, 1967, at the Los Angeles Memorial Coliseum in Los Angeles."
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-10)        ]
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-11)    )
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-12)scorer = FaithfulnesswithHHEM(llm=evaluator_llm)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-5-13)await scorer.single_turn_ascore(sample)

```

You can load the model onto a specified device by setting the `device` argument and adjust the batch size for inference using the `batch_size` parameter. By default, the model is loaded on the CPU with a batch size of 10:

```
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-6-1)my_device = "cuda:0"
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-6-2)my_batch_size = 10
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-6-3)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-6-4)scorer = FaithfulnesswithHHEM(device=my_device, batch_size=my_batch_size)
[](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/#__codelineno-6-5)await scorer.single_turn_ascore(sample)

```
