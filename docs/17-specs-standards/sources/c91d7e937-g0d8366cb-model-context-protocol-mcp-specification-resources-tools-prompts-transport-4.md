# Model Context Protocol (MCP)
Welcome to the Model Context Protocol documentation!
MCP is a standardized protocol designed to enhance the interaction between Large Language Models (LLMs) and applications by providing structured context management.
## Quick Start [](https://modelcontextprotocol.info/docs/#quick-start)
  * **[Quick Start](https://modelcontextprotocol.info/docs/quickstart/)** - Get started with MCP in 5 minutes
  * **[Client](https://modelcontextprotocol.info/docs/clients/)** - Installation and usage guides for different language clients
  * **[Build an MCP Client (Core)](https://modelcontextprotocol.info/docs/development/build-client/)** - Minimal viable implementation with official examples


## Core Concepts [](https://modelcontextprotocol.info/docs/#core-concepts)
MCP’s core features and concepts include:
  * **[Sampling](https://modelcontextprotocol.info/docs/concepts/sampling/)** - Understanding MCP’s sampling mechanisms and strategies
  * **[Transport](https://modelcontextprotocol.info/docs/concepts/transport/)** - Data transport and communication protocols
  * **[Tools](https://modelcontextprotocol.info/docs/concepts/tools/)** - MCP toolset and usage guidelines
  * **[Architecture](https://modelcontextprotocol.info/docs/concepts/architecture/)** - System architecture and design principles
  * **[Prompts](https://modelcontextprotocol.info/docs/concepts/prompts/)** - Prompt engineering and best practices
  * **[Resources](https://modelcontextprotocol.info/docs/concepts/resources/)** - Related resources and references


## Extensions [](https://modelcontextprotocol.info/docs/#extensions)
  * **[Extensions](https://modelcontextprotocol.info/docs/extensions/)** - Official MCP extensions (MCP Apps, OAuth, etc.)


## Why Choose MCP? [](https://modelcontextprotocol.info/docs/#why-choose-mcp)
  * **Standardization** : Unified interfaces and protocols to simplify development
  * **Efficiency** : Optimized context management for enhanced model interactions
  * **Extensibility** : Flexible architecture supporting custom extensions
  * **Ease of Use** : Simple and intuitive APIs with low barrier to entry
